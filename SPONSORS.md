# Sponsors

MCP Test Harness is **MIT licensed** and maintained in the open. Sponsorship and adoption support ongoing development: CI gates, conformance tooling, provider packages, docs, and the GitHub Pages site.

## Why sponsor

| Sponsor benefit | What it funds |
|-----------------|---------------|
| **Predictable MCP CI** | Core harness, transports, reports, and GitHub Action maintenance |
| **Ecosystem reach** | The 17 optional provider shim packages on PyPI |
| **Production readiness** | Coverage gates, seam e2e tests, distribution smoke (Docker, PyInstaller, Action) |
| **Visibility** | Logo/name on this page and optional README mention (by tier) |

## Ways to support (no payment required)

- **Star** the repo on [GitHub](https://github.com/vaquarkhan/mcp-test-harness) - helps discovery and signals adoption.
- **Contribute** code, docs, or examples - see [CONTRIBUTING.md](CONTRIBUTING.md).
- **Adopt in CI** - pin `mcp-test-harness` in your pipeline and share feedback via Issues.
- **Cite** the project in papers or blog posts - see [CITATION.cff](CITATION.cff).

## Sponsorship tiers (guideline)

These tiers are a starting point for organizations that want formal support. Contact the maintainer to discuss invoicing, SLAs, or private enablement.

| Tier | Suggested contribution | Recognition |
|------|------------------------|-------------|
| **Bronze** | Any recurring or one-time support | Name in this file |
| **Silver** | Priority issue triage for your team | Name + link in README sponsors section |
| **Gold** | Roadmap input + logo placement | Logo on GitHub Pages + README |
