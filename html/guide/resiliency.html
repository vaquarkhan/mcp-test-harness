Resiliency testing

Prove the MCP session recovers from disconnects, crashes, and partial failure — with assertion helpers and an optional experiment catalog scorecard.

reconnect · crash · degrade
Catalog

Assertion helpers

from mcp_test_harness import (
    assert_reconnects,
    assert_survives_crash,
    assert_degrades_gracefully,
    marker,
)

@marker(tags=["resiliency"])
async def test_session_reconnects(mcp_server):
    await assert_reconnects(mcp_server)

Experiment catalog (RFC-005)

Run curated resiliency scenarios with guardrails and a scorecard:

mcp-test experiment list
mcp-test experiment run --suite core
mcp-test experiment run graceful-degradation --verbose
